        USB port choice
        Two ports? Use native USB
        
If a board exposes both a USB-to-UART bridge and the ESP chip's own USB port, select the port named USB JTAG/serial debug unit or ESP32. A CH340, CH343, CP210x or FTDI bridge may fail with Failed to connect with the device or stop part-way through. Retry with the socket labelled USB/native, not UART/COM.
